Windows desktop preview release notes

Release details

Preview build. The installer is unsigned, so Windows SmartScreen will warn. Verify the SHA-256 before choosing More info → Run anyway.

Summary

v1.4.2 adds a first-run Terms & Privacy gate, desktop sign-up, remembered sign-in emails, and offline library resume.

It was built from the desktop-parity branch at commit 815b8fa46ae07f3a7d4f08810138ec5e624fd27b. That branch has not been merged into test3.

Status

  • Preview, not stable: treat it as a working build for testing, not a final desktop release.
  • Unsigned: Windows SmartScreen will warn until the installer is code-signed and builds reputation.
  • Real-device pass: tested end to end on a Dell Latitude E7240, 8 GB RAM, 128 GB SSD, Windows 11 Pro 25H2. The exact OS build number was not recorded.
  • Still pending: a second clean Windows 10/11 virtual machine, an upgrade install from an older desktop build, and the final code-signing choice.

Installation

  1. Download NIMELSSA-Vault-1.4.2.exe from the card on this page.
  2. Verify the SHA-256 with certutil before running it.
  3. Run the installer. If SmartScreen appears, choose More info → Run anyway only after the hash matches.
  4. Open NIMELSSA Vault and sign in with an approved account.
  5. To update later, open Settings → Updates; the app checks the public release, verifies the SHA-256, and launches the installer.

Verify

Compare the full SHA-256 before running the installer:

541f877849ec81feff2d6c8cefe856c78546ff8d87323857f08820987806eaea 
certutil -hashfile NIMELSSA-Vault-1.4.2.exe SHA256

Configuration

  • The installer does not bundle google-services.json or a service-account credential.
  • The desktop build uses public client API keys for Firebase and Drive. Firestore rules remain the access-control boundary.
  • Use a separate Drive API key for desktop; do not reuse the Android-restricted key.
  • Settings → Updates checks the public desktop release feed; it verifies SHA-256 before launching the installer.

Known issues

  • SmartScreen warns because the installer is unsigned.
  • Only one real Windows machine has been exercised end to end.
  • Clean Windows 10/11 VM and upgrade-install validation are still pending.
  • Offline resume requires one successful online library load on this machine.
  • New desktop accounts still need admin approval before the library unlocks.
  • desktop-parity is not merged, so desktop fixes can land separately from Android releases.

FAQ

Is this the Android app?

No. This is a separate Windows desktop preview with its own version number and installer. Android releases continue on the Android download tab.

Is the installer signed?

No. It is an unsigned preview. Check the SHA-256 before running it, and expect a SmartScreen warning.

Does it update itself?

Yes. Open Settings → Updates to check the public desktop release. The app downloads the installer and verifies its SHA-256 before launching it.

Does this affect Android?

No. The Android APK, update feed, signing key, and release notes are separate.

Where do I report a desktop issue?

Email israelagboola53@gmail.com with the Windows build number and the step that failed.
