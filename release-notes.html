Release notes

NIMELSSA Vault v1.3.7

A clearer What's New experience, tidier staff navigation, and automatic role refresh when the drawer opens.

Latest release · Released 11 Nov 2026 · 4.7 MB download · ~18 MB installed before downloads · Android 8.0+ · 0 downloads

Release v1.3.7. Install it once from this page, and later releases arrive through Settings → APP UPDATE. v1.1.1 was debug-signed and still needs a one-time uninstall before a release-signed build can install.

Summary

A clearer What's New experience, tidier staff navigation, and automatic role refresh when the drawer opens.

This update keeps your existing data and installs over v1.3.1 or later without a reinstall. The changelog below lists the full set of changes.

The in-app updater, three-lifeline policy, and SHA-256, package name, versionCode, and signing-certificate checks are unchanged.

Key Features

  • Version: versionCode 12 / versionName 1.3.7.
  • Signed APK: 4.7 MB download.
  • What changed: scrollable What's New dialog, drawer-only staff tools, attention dots, and automatic role refresh.
  • Verified install: SHA-256, package name, versionCode, and signing certificate are checked before install.
  • In-place update: v1.3.1 and later use the same release signing key, so no uninstall is needed.

Installation

  1. If you are on v1.1.1 (debug-signed), uninstall it once. Back up anything you need first.
  2. Install NIMELSSA-Vault-v1.3.7.apk from the download card on this page, or update from Settings → APP UPDATE inside the app.
  3. Android may ask you to allow installs from NIMELSSA Vault the first time. Grant it once; the permission is scoped to this app.
  4. Open the app and sign in. Verify your email and complete the access gate if prompted.
  5. Pinned files, saved resources, and a chosen Download location carry over; updating from v1.3.1 or later does not clear app data.

Configuration

  • No new required keys and no google-services.json changes.
  • The update feed is the public release.json on this site; no GitHub account is required to check, download, or read the notes.
  • Android's install-unknown-apps permission is requested the first time the app hands an APK to the installer. It is app-scoped and can be revoked in Android settings.
  • Firestore rules, the access gate, and the Drive API key are unchanged from the previous release.
  • The Windows desktop client is a separate read-only build with its own Drive key and is not affected by this release.
  • The download folder remains a user-selected Android SAF folder and is not a Firebase setting.

Changelog

Changed

  • Version bumped to versionCode 12 / versionName 1.3.7.
  • What's New now opens as a scrollable dialog over the workspace.
  • Staff tools live only in the drawer; Reports and Duplicates are no longer repeated as tabs.
  • The hamburger menu shows a red dot when staff attention is needed.
  • Role and notification access refresh automatically when the drawer opens.
  • Reps can delete duplicate entries.

FAQ

What changed in v1.3.7?

This release adds a scrollable What's New dialog, moves staff tools into the drawer, adds attention dots, and refreshes role access when the drawer opens. See the changelog above for the full list.

Do I need to reinstall?

No reinstall is needed from v1.3.1 or later. Those builds share the same release signing key and update in place. v1.1.1 was debug-signed and still needs a one-time uninstall, which clears app-private files; Firebase-backed data returns after sign-in.

Is the updater verified?

The release APK passes the unit suite, the R8 release build, and apksigner verification in CI. The app also checks SHA-256, package name, versionCode, and the signing certificate before install.

Does this affect the Windows desktop client?

No. The desktop client is a separate read-only build with its own Drive key and configuration. This release only refreshes the Android APK and its public download feed.
